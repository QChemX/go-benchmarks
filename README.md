Test the performance of CPU using a CLI tool built in Go.

## Usage

```bash
$ ./benchmarks --help
Usage of ./benchmarks-linux-amd64:
  -iters int
        number of iterations (default 3)
  -n int
        matrix size (N x N) (default 600)
```
